# 커브(Curve) 서비스 컨셉

> 같은 학과, 다른 커브.

최종 수정: 2026-11-20

---

## 1. 한 줄 정의

**뭘 검색해야 할지조차 모르는 대학생에게, 커리어 탐색의 출발점을 만들어 주는 서비스.**

학생이 학교·학과·고민을 알려 주면, 커브가 볼 만한 주제를 추천해요. 학생은 그중에서 담고 싶은 항목을 직접 골라요. 커브는 고른 항목으로 **표지 + 최대 7페이지, 총 8페이지 분량의 커리어 로드맵 문서**를 만들어 줘요.

---

## 2. 왜 필요한가

### 학생이 겪는 문제

- 진로가 아직 없고, 뭘 좋아하는지도 모르겠어요.
- 공무원이냐 취업이냐를 두고 몇 달째 고민해요.
- 학점은 괜찮은데, 그다음에 뭘 해야 할지 막막해요.
- 다들 뭔가 하고 있는데 나만 멈춰 있는 것 같아요.

### 기존 방식의 한계

- **검색과 AI 질문은 "뭘 물어야 하는지 알 때"만 쓸모가 있어요.** 검색어를 아는 학생은 이미 스스로 찾아요. 막막한 학생은 첫 질문을 만들지 못해요.
- **정보를 한꺼번에 주면 양은 많아도 흥미가 생기지 않아요.** 처음 만든 버전(고정된 7개 장)에서 확인한 문제예요. 학생이 고르지 않은 내용은 끝까지 읽히지 않았어요.

### 커브의 답

커브의 차별점은 **정보를 알려 주는 것이 아니라, 무엇을 알아봐야 하는지 보여 주는 것**이에요.

추천 항목을 펼쳐 보는 것만으로 "이런 것도 알아봐야 하는구나"를 알게 돼요. 리포트를 받기 전에도 가치가 생겨요. 그리고 직접 고른 목차라서 끝까지 읽을 이유가 생겨요.

---

## 3. 대상

- **주 대상:** 전국 4년제 대학 재학생, 특히 1~3학년
- **이런 학생에게 특히 맞아요**
  - 진로를 아직 못 정해 넓게 둘러보고 싶은 학생
  - 가고 싶은 길은 있는데 무엇부터 준비할지 모르는 학생
  - 두세 개 후보 사이에서 비교하고 싶은 학생

## 4. 사용 흐름

```
① 나를 알려 주세요  →  ② 목차를 직접 골라요  →  ③ 나만의 로드맵을 받아요
```

### ① 나를 알려 주세요 (질문 6개)

| 순서 | 질문 | 비고 |
|---|---|---|
| 1 | 이름(닉네임), 나이 | 선택 |
| 2 | 학교, 학과, 학년 | 필수 |
| 3 | 요즘 신경 쓰이는 쪽 | 필수. 진로/취업 · 학점 · 돈 벌기 · 인간관계 · 자기계발 · 취미여가 · 연애 중 **우선순위대로 최대 3개** |
| 4 | 지금 목표 | 선택. "아직 없어요" 가능. 적으면 가까운 추천 항목에 "목표와 가까워요" 표시 |
| 5 | 앞으로 1년간 세워 둔 계획 | 선택. 재학 · 알바 · 군대 · 여행 · 자격증/대외활동/공모전 · 동아리 · 기타(직접 입력) 중복 선택 |
| 6 | 성향(MBTI) | 선택. 참고용 |

### ② 목차를 직접 골라요 (질문 7)

학생에게 맞춘 **추천 트리**에서 로드맵에 담을 항목을 최대 7개 골라요. 자세한 규칙은 5장에 있어요.

### ③ 나만의 로드맵을 받아요

- **표지:** 이름, 학교·학과·학년, 관심 우선순위, 목표, 1년 계획, 성향, 그리고 트리 순서로 들여쓴 목차
- **본문:** 고른 항목 하나가 한 페이지예요. 페이지마다 어떤 경로로 골랐는지 보여 줘요(예: 자동차·모빌리티 › 자작자동차 동아리와 대회).

## 5. 핵심 기능: 목차 고르기

### 기본 규칙

| 규칙 | 내용 |
|---|---|
| 칸 수 | **최대 7칸**. 표지까지 합쳐 8페이지 |
| 칸 계산 | 상위 항목이든 하위 항목이든 **고른 항목 하나가 한 칸** |
| 최소 | 하나 이상 고르면 로드맵을 받을 수 있어요 |
| 깊이 | 정해진 단계 없음. **칸이 남는 한 계속 내려갈 수 있어요** |
| 빼기 | 상위 항목을 빼면 **그 아래에서 고른 항목도 함께 빠져요** |
| 목차 순서 | 고른 순서가 아니라 **트리 순서**로 정리해요(상위 → 하위가 이어서 읽히도록) |

### 1단계 추천 구성

- **학과별 진로 후보 4~6개**
- **학생이 질문 3에서 고른 관심 카테고리의 공통 가지.** 진로/취업을 뺀 학점, 돈 벌기 등이 1단계에 함께 나와요.

### 두 가지 사용 방식

같은 7칸으로 학생이 방식을 정해요.

| 방식 | 고르는 법 | 이런 학생에게 |
|---|---|---|
| **넓게 보기** | 1단계에서 여러 진로를 한 장씩 | 아직 모르겠는 학생. 마음에 드는 게 생기면 다음엔 깊게 |
| **깊게 파기** | 한 진로를 골라 이어지는 주제로 계속 내려가기 | 가고 싶은 길이 있는 학생 |

### 하위 항목을 만드는 원칙: 쪼개기가 아니라 넓혀 가기

하위 항목은 상위 항목을 잘게 나눈 것이 아니라, **이어서 볼 다음 주제**예요.

| 방식 | "백엔드 개발자" 아래 | "코딩 테스트" 아래 |
|---|---|---|
| 쪼개기 (쓰지 않음) | 기술 스택, 코딩 테스트 | 알고리즘 공부 순서, 출제 경향 |
| 넓혀 가기 (사용) | 코딩 테스트, 포트폴리오, 인턴십과 채용 시즌, 직군 비교 | 알고리즘 동아리와 대회 |

"알고리즘 공부 순서" 같은 세부 내용은 사라지지 않고, 상위 항목 페이지 안의 소제목으로 들어가요.

### 한 페이지 크기 기준

항목이 되려면 다음 중 **세 가지 이상**을 말할 수 있어야 해요.

- 무엇인지
- 왜 중요한지
- 지금 학년에 할 일
- 일정
- 막히기 쉬운 지점

표 한 줄이나 팁 하나로 끝나는 내용은 항목이 아니라 상위 페이지의 소제목이에요. 더 내려갈 한 페이지짜리 주제가 없으면 그 아래로는 추천을 띄우지 않아요.

## 6. 리포트 페이지 형식

**형식은 항목마다 자유로워요.** 필요한 블록만 골라 순서대로 써요.

| 블록 | 쓰임 |
|---|---|
| 소개 | 페이지 첫머리 2~3문단 |
| 소제목, 본문 | 페이지 안 작은 주제 |
| 표 | 종류·조건 정리 |
| 비교 | 두세 가지 선택지를 나란히 |
| 단계 | 준비 순서, 정리하는 틀 |
| 일정 | 시기별 흐름 |
| 체크리스트 | 이번 학기·이번 달에 해 볼 것 |
| 핵심 | 이 페이지에서 꼭 가져갈 한 문장 |
| TIP | 선배가 알려 주는 요령 |
| 가정 | 확인되지 않았거나 바뀔 수 있는 내용 표시 |
| 출처 | 실제로 존재하는 기관·누리집만 |

**넣지 않기로 한 것:** 페이지마다 "다음에 검색해 볼 것"을 붙이지 않아요. 검색은 학생이 자유롭게 하는 게 좋고, 거기까지 알려 주면 간섭받는 느낌이 들 수 있어요.

## 8. 커브의 약속

1. **우리 학교의 진짜 정보:** 학과, 장학, 취업박람회, 상담 창구까지 내 학교에 실제로 있는 정보를 담아요.
2. **지금의 정보:** 시험 제도와 채용 공고처럼 바뀌는 정보는 매번 새로 조사해요.
3. **정직한 문서:** 가정은 가정이라고 적어요. 확인된 것만 사실로 쓰고 출처를 남겨요.
4. **내가 고른 목차:** 무엇을 담을지 내가 직접 골라요. 같은 학과라도 같은 문서는 없어요.
5. **MBTI는 참고만:** 성향은 힌트일 뿐, 성격 유형으로 진로를 정해 주지 않아요.

## 9. 지금 단계: 고객 피드백 수집

- **무료 체험 기간이에요.** 유료, 가격, 결제, 잠금 같은 요소는 어디에도 두지 않아요.
- **샘플 리포트는 전체를 선명하게 공개해요.** 흐림이나 가림 처리를 하지 않아요.
- **핵심 행동은 피드백이에요.** 메인 페이지 피드백 폼으로 받고, 내용은 Formspree로 모여요.
  - 로드맵이 얼마나 도움이 될 것 같은지(1~5점)
  - 목차를 직접 고르는 방식은 어땠는지
  - 추천에 없어서 아쉬웠던 항목
  - 학교·학년, 출시 소식을 받을 이메일(선택)

### 체험판 범위

| 항목 | 현재 상태 |
|---|---|
| 시연 학과 | 입력한 학과와 상관없이 **기계공학과 트리**로 시연(화면에 안내 표시) |
| 확정된 추천 트리 | 컴퓨터학부, 기계공학과, 경영학과 + 공통 가지 6개 (총 82개 항목) |
| 페이지 본문 | 기계공학과 20개와 공통 가지 14개는 짧은 미리보기 버전. 메인 샘플 경로 7개는 한 페이지 분량 |
| 리포트 생성 | AI 연동 전. 미리 만든 트리와 본문으로 목업 생성 |

### 메인 페이지 샘플

가상 인물 **김하린**(커브대학교 경영학과 2학년)이 마케팅과 공기업 사이에서 고민하며 고른 7개 항목이에요.

```
1  마케팅
2  └ 마케팅 공모전
3     └ 공모전 경험 정리하기
4  공기업 사무직
5  └ NCS 필기
6  대학생 수입 만들기   (돈 벌기)
7  └ 장학금 찾기
```
